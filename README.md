# fakeOLX

Aplikacja mobilna na Androida (Kotlin) wzorowana na serwisie ogłoszeniowym OLX —
przeglądanie i dodawanie ogłoszeń.

## Stack

- Kotlin
- Android SDK
- Gradle (Kotlin DSL)

## Uruchomienie

Otwórz projekt w Android Studio i uruchom na emulatorze lub urządzeniu (**Run**).
Alternatywnie z konsoli:

```bash
./gradlew assembleDebug
```
